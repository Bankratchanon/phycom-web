บทคัดย่อ

Safe A-Train คือระบบทางกั้นรถไฟจำลองที่ควบคุมด้วย Arduino UNO R4 WiFi 2 บอร์ด ตรวจจับรถไฟด้วยเลเซอร์ 2 จุด และสื่อสารกันผ่าน MQTT ระบบทำงานได้ทั้งโหมด Automatic ที่ปิด-เปิดทางกั้นเองทั้งหมด และโหมด Manual ที่ผู้ควบคุมสั่งปิดผ่าน Wi-Fi โดยมีตัวจับเวลาความปลอดภัยสั่งปิดทางกั้นให้อัตโนมัติหากผู้ควบคุมไม่ได้ปิดภายในเวลาที่กำหนด เพื่อลดความผิดพลาดจากมนุษย์และลดอุบัติเหตุที่จุดตัดรถไฟ

ที่มาและเป้าหมาย

ทางผ่านรถไฟที่ต้องใช้คนกดไม้กั้นเอง เสี่ยงต่อความผิดพลาด เช่น ลืมกดหรือกดช้า เราจึงทำระบบที่ตรวจจับรถไฟล่วงหน้า แจ้งเตือนผู้รับผิดชอบ และลดไม้กั้นให้เองหากไม่มีใครกด

ขั้นตอนการทำงาน

1. ตรวจพบรถไฟ

  • เลเซอร์จุดแรกถูกบัง
  • Buzzer ส่งเสียงเตือน
  • ส่งค่าผ่าน MQTT ไปยังอีกบอร์ด
  • ไฟ เขียว → เหลือง

2. ลดไม้กั้น

  • แจ้งเตือนผู้รับผิดชอบให้กดลดไม้กั้น
  • ถ้าไม่กด ระบบลดให้เองก่อนรถไฟมาถึง
  • ไฟ เหลือง → แดง
  • Servo ลดไม้กั้นลง

3. รถไฟผ่านไปแล้ว

  • เลเซอร์จุดที่สองตรวจว่ารถไฟผ่านไปแล้ว
  • Servo ยกไม้กั้นขึ้น
  • ไฟ แดง → เขียว

โหมดการทำงาน

Manual

ผู้รับผิดชอบกดลดไม้กั้นผ่าน Blynk ถ้าไม่กด ระบบลดให้เองเพื่อป้องกัน Human error

Auto

ระบบทำงานเองทั้งหมด ไม่ต้องมีคนกดลดหรือยกไม้กั้น

อุปกรณ์ที่ใช้

อุปกรณ์จำนวนหน้าที่
Arduino UNO R4 WiFi2สมองของระบบ เชื่อม WiFi และ MQTT
Laser2ยิงแสงข้ามราง
Laser Detector Module2ตรวจว่าแสงถูกบังหรือไม่ (มีรถไฟผ่าน)
SG90 Servo Motor1ขยับไม้กั้น
LED Module 3 สี (ไฟจราจร)1แสดงสถานะ เขียว / เหลือง / แดง
Active Buzzer Module1ส่งเสียงเตือน
รถไฟของเล่นพร้อมราง1ใช้จำลองสถานการณ์

ซอฟต์แวร์/บริการ: HiveMQ WebSocket Client, Blynk IoT (Web)

ปัญหาที่เจอและแนวทางพัฒนาต่อ

  • ปัญหาที่เจอ: การตั้งค่าให้บอร์ดส่งคำสั่งขึ้น MQTT แล้วอีกบอร์ดรับคำสั่งนั้นทำได้ช้า แต่สามารถแก้ได้แล้ว , สายไฟเสีย , การอ่านค่าบางทีอาจไม่ถูกต้องเลยต้องมาแก้โค้ดใหม่
  • แนวทางพัฒนาต่อ: เพิ่มการแจ้งเตือนบนมือถือให้สามารถนำไปใช้ได้จริง
